# Openwater

A little ocean to get lost in.

**[Open the ocean](https://openwater.alirezaafshan.com)**

An interactive Three.js seascape inspired by [Dan Greenheck's Water Pro V3 demonstration](https://x.com/dangreenheck/status/2062278887388991549), independently implemented with original shaders and procedural scene geometry.

- Layered directional swells, small wind waves, Fresnel reflections, sun glints, shallow-water color and procedural caustics.
- Crest and shoreline foam, a moving ship's wake, spray, and rain.
- An original two-masted ship, palm island, rocks, floating buoy, and seabirds.
- Cove, open-sea, and sailing camera views; trade winds, golden hour, storm, and moonlight presets.
- Live wind, swell, sun, whitecap, and rain controls; adjustable rendering detail.
- Tap-to-ripple, opt-in synthesized sea sound, pause, clean postcard export, and shareable conditions.
- Touch orbit/pinch controls, keyboard shortcuts, and an initially paused scene for reduced-motion preferences.

## Run

Requires Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
npm start
```

The dev server runs on port 5173. Production runs on port 8080, with `/healthz` and `/version.json` providing release identity. The Dockerfile builds and serves the static site as a non-root user.

## Compact player

`/embed` opens the same ocean with just view, weather, pause, and an "Open ocean" link that carries those conditions into the full site. It uses a 4:3 preview, stays usable in narrow frames, and suspends the animation loop while offscreen. The homepage provides Open Graph and X Player Card metadata; the Node server permits the compact route to be framed by X/Twitter and Alireza's homepage/portfolio. Other parent sites need to be added deliberately.

Interactive Player Cards depend on the destination client. A local working iframe and a successful card validator do not establish playback inside a published X post.

## Controls

Drag to orbit; right-drag to pan; scroll or pinch to zoom. Tap water for a ripple. `1`, `2`, `3` change views, `Space` pauses, and `H` hides the interface. The sliders open from the upper-right controls button. “Copy this ocean” preserves the selected view, weather, custom conditions, and ship visibility in the URL.

## Implementation and scope

The ocean is a deterministic 12-mode Gerstner approximation with a separate high-frequency normal band. Reflection is a planar render pass using Three.js's MIT-licensed Water helper. Foam and wakes are procedural visual approximations; they are not a persistent fluid simulation. The ship's wave-following movement is scripted, not navigable sailing physics. This recreation does not use Water Pro and does not claim its FFT, multiplayer, underwater, or performance capabilities. It requires WebGL 2.

The sky is a self-hosted CC0 Poly Haven HDRI; see [asset provenance](public/assets/README.md). Geometry and other surface textures are generated by the application. Three.js is MIT licensed. UI fonts are DM Sans and Manrope (SIL Open Font License), loaded from Google Fonts with system fallbacks.

Deployment uses Alireza's existing VPS and Deploy Manager, with candidate health checks, exact-SHA releases, and signed release receipts. See [deployment notes](docs/deployment.md).
